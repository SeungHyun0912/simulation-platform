# 프런트엔드 수동 검증 체크리스트

자동 테스트(jsdom)가 보장하지 못하는 항목입니다. 화면을 추가·변경할 때마다 확인하고,
결과는 해당 작업의 인계 문서(docs/handoffs)에 날짜와 함께 기록합니다.
상태: 아래 항목 중 "확인됨"으로 표시한 것만 실제로 확인한 것입니다.

## 실행 방법
```bash
cd frontend
pnpm install
pnpm dev        # http://localhost:5173
```
정적 단계 화면: `/projects/demo-a/assets`, `/projects/demo-a/products`.
상태 화면은 주소 뒤에 `?state=loading|error|empty|forbidden|conflict`를 붙여 확인합니다.

## 2. 키보드·포커스 (모두 미확인)
- [ ] Tab 순서가 시각 순서와 같고 모든 조작 요소에 포커스 표시가 보임
- [ ] 본문 건너뛰기 링크가 첫 Tab에서 나타나고 본문으로 이동
- [ ] 프로젝트 전환 메뉴: Enter/Space로 열기, 화살표 이동, Esc로 닫기, 닫은 뒤 트리거로 포커스 복귀
- [ ] 확인 대화상자: 열리면 포커스가 안으로 이동하고 Tab이 밖으로 나가지 않음, Esc로 닫으면 호출 요소로 복귀
- [ ] 정렬 버튼·상태 라디오(미정/값 있음/…)를 키보드로 조작 가능
- [ ] 표 영역(role=region, tabindex=0)에서 화살표로 스크롤 가능

### 공정 표 편집 (초안 UI) — 미확인
- [ ] "편집"을 누르면 편집 패널 제목으로 포커스가 이동하고, "편집 닫기" 후 그 행의 편집 버튼으로 돌아옴
- [ ] ▲▼ 이동 후에도 포커스가 같은 단계의 버튼에 남거나 예측 가능한 위치에 있음(현재는 보장하지 않음)
- [ ] 삭제 확인 대화상자: Esc/취소 후 삭제 버튼으로 포커스 복귀
- [ ] 편집 패널이 열린 채 표가 넓을 때 표 영역 가로 스크롤과 패널 위치가 어색하지 않음
- [ ] 처리 방식·산출 방식 변경으로 값이 사라질 때 확인 창이 뜨고, 취소하면 선택과 값이 그대로 유지되며, 취소 뒤 포커스가 선택 상자로 돌아옴
- [ ] 같은 단위(분)로 바뀌는 방식 사이에서는 확인 없이 값이 유지됨(자동 테스트는 있음, 화면 확인은 미실시)

### 실제 API 모드(`VITE_DATA_SOURCE=api`)
- 확인됨(2026-10-23, Edge 헤드리스, 1280px): 프로젝트 목록(DEMO-A·B·DEV-PROJECT, 관리자 역할), 자산 목록(버전 상태 배지), 자산 상세(EQ-005: 승인본 v1 + 초안 v2, 포트별 용량·규칙, 이력)
- [ ] 전환 메뉴로 프로젝트를 바꿀 때 이전 프로젝트 목록이 잠깐이라도 보이지 않음(자동 테스트는 있음, 화면 확인은 미실시)
- [ ] 서버를 끄거나 느리게 했을 때의 안내(연결 실패 + 다시 시도), 로딩 표시, 정렬 중 "목록을 새로 불러오는 중…"
- [ ] 조회자(`viewer`)·편집자 사용자로 바꿔(`DEV_DEBUG_USER`) 읽기 전용과 버튼 노출이 실제 서버 역할과 일치
- [ ] 다른 조직 사용자로 프로젝트 A 주소에 직접 접근하면 "찾을 수 없음"(존재를 알리지 않음)
- [ ] 정적 예시가 API 모드 화면에 섞여 보이지 않음(제품·공정은 예시임을 표시)

### 자산 저장·생성(API 모드) — 미확인
- 확인됨(2026-10-23): 자산 추가 화면 레이아웃(1280px 스크린샷), 실서버 PATCH 규칙(428·412·409·422·403·404, 원복 포함)
- [ ] 저장 중 버튼 문구("저장 중…")와 저장 완료 알림(`role=status`)이 스크린리더에 낭독되는지
- [ ] 충돌 안내가 나타날 때 포커스·낭독, "내 변경을 유지하고 계속 편집" 후 병합 결과(서버 값 안내 문구)를 이해할 수 있는지
- [ ] 서버 필드 오류(코드 중복 등)가 입력과 연결되어 낭독되고, 고치기 시작하면 사라지는지
- [ ] 자산 생성 직후 상세로 이동했을 때 포커스 위치(제목)와 미저장 확인 창이 뜨지 않는지(자동 테스트는 있음)
- [ ] 연결이 끊겼을 때 "저장 여부를 알 수 없음" 안내와 코드 재검색 링크(생성)가 이해되는지
- [ ] 실서버로 **자산 생성**은 실행하지 않았다(삭제 불가로 흔적이 남음). 사용자가 허용하면 `DEV-PROJECT`에서 한 번 확인

### 설비 상세 (계약 0.2.0 구조) — 미확인
- [ ] 기본 정보 / 용량·규칙(버전) / 포트 구역의 Tab 순서와 제목 읽기 순서가 자연스러움
- [ ] 버전 선택 상자를 바꾸면 상태 문구·읽기 전용 안내·입력 활성 상태가 함께 바뀜(스크린리더 알림 포함)
- [ ] 용량 값 오류(0, 선행 0, 소수 7자리)가 입력과 연결되어 낭독되고, 오류 패널과 중복 낭독이 과하지 않음
- [ ] 섹션별 충돌 안내의 두 버튼 키보드 조작, "다시 불러오기" 후 포커스 위치
- [ ] 조회자·편집자 계정에서 읽기 전용 입력의 글자 대비와 숨겨진 버튼이 자연스러움
- [ ] 좁은 폭(600px, 가능하면 휴대폰 폭)에서 상세 화면이 가로로 넘치지 않음(1280px 정상 상태만 스크린샷 확인함, 2026-10-23)
- [ ] 경고가 4건 이상일 때 접힌 경고 요약의 키보드 열기·낭독

### 프로젝트 목록·만들기 — 미확인
- [ ] 목록에서 프로젝트 코드 링크로 열면 해당 프로젝트 화면으로 이동하고 상단 현재 프로젝트가 바뀜
- [ ] 만들기 폼: Tab 순서, 오류 낭독, 입력 후 "프로젝트" 경로 링크로 이동 시 미저장 확인 창
- [ ] 프로젝트가 선택되지 않은 화면(목록·만들기)에서 사이드 메뉴가 없어도 이동에 불편이 없음

## 3. 스크린리더 (모두 미확인)
- [ ] 입력 필드가 라벨과 오류·힌트를 함께 읽음
- [ ] 검증 패널·충돌 안내가 나타날 때 알림으로 읽힘
- [ ] 정렬 상태(aria-sort)와 현재 위치(breadcrumb)가 읽힘
- [ ] 상태 배지가 색 없이 글자만으로도 구분됨

## 4. 색·대비 (모두 미확인)
- [ ] 본문·보조 글자·상태 배지의 대비가 4.5:1 이상(도구로 측정)
- [ ] 비활성 버튼과 읽기 전용 입력의 글자가 읽을 수 있음(현재 연한 색을 사용)
- [ ] 색을 흑백으로 바꿔도 상태 구분 가능

## 5. 프로젝트 전환·미저장 보호
- [ ] 입력 후 프로젝트 전환 시 확인 창이 뜨고 취소하면 입력이 유지됨
- [ ] 전환 후 이전 프로젝트의 값이 화면에 남지 않음
- [ ] 입력 후 브라우저 탭 닫기·새로고침 시 경고(beforeunload)
- [ ] 실제 API 연동 후: 전환 중 진행 중인 요청이 취소되고 이전 응답이 새 화면에 반영되지 않음

## 6. 한국어 표기
- [ ] 화면 문구에 한자·일본어가 섞여 있지 않음

## 7. 자산 버전 쓰기 (FE-01d) — 모두 미확인
- [ ] 용량 값 입력 → 저장 → 저장 완료 알림이 낭독되고, 저장 전에는 "저장하지 않은 변경" 표시와 미저장 이동 경고가 나옴
- [ ] 이동·배출 규칙 선택(Tab 순서, 선택지 문구에 D-U05/D-U06/OPEN-003 근거가 읽힘), 미정으로 바꿀 때 확인 창에서 Esc=취소, 닫은 뒤 포커스가 원래 선택 칸으로 돌아옴
- [ ] 반려 사유 창: 열면 사유 입력에 포커스, 공백만 입력하면 반려 버튼 비활성, Esc로 닫으면 입력 폐기, 닫은 뒤 포커스가 "반려" 버튼으로 복귀
- [ ] 충돌 안내(용량 버전)가 나타날 때 알림으로 읽힘, 자산 기본 정보 충돌과 구분됨
- [ ] 서버 필드 오류(포트별 용량·규칙)가 해당 입력 옆에서 읽힘
- [ ] 좁은 화면(≤768px)에서 규칙 입력 2칸이 세로로 쌓이고 가로 스크롤이 없음
- [ ] 실서버(공유 개발 DB, 사용자 허락 후): 저장·제출·승인·반려·새 초안 흐름과 상태 배지 갱신
