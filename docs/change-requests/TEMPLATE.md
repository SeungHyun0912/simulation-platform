# CR-역할-날짜-주제
- 작성자/담당:
- 상태: PROPOSED / APPROVED / REJECTED / IMPLEMENTED
- 기준 commit / 계약 버전:
- 유형: 도메인 정정 / ERD / API / 환경 / 기술 채택
- 변경 대상과 현재 값:
- 변경 이유와 사용자 근거:
- 제안:
- 영향받는 테이블·migration·화면·API·예제·엔진:
- 호환성/데이터 변환/롤백:
- 미정·위험:
- 필요한 테스트:
- 승인자 / 승인일 / 근거:
- 반영 commit / 양쪽 확인:
APPROVED와 IMPLEMENTED를 구별한다. 사용자 생산 규칙은 기술 담당자가 임의 승인하지 않는다.
