# 15. 변경 이력·구현 상태

## 패키지1.0.0 — 2026-10-22

### 추가
- 프로젝트 기반 범용 플랫폼의 DB/ERD·도메인·API·Backend·Frontend 기술서.
- SimPy 의미론·검증·이벤트·지표·운영 설계.
- 제품6종/설비96대/공간22곳 최신 사용자 데이터.
- 위키·LLM·CAD 경계, 외부 에이전트 인계 가이드.
- 단계별 로드맵과 미정 질문·ADR.
- 공식 기술문서 참조 목록.

- AL 재권취 EQ-085~088.
- P05 연선100,000m1:1, 절연에서24,000m×4 분할.
- P05 1차조사1:1, 절연잔량4,000m 처리미정.
- P06 최초절연은쉬스압출기, 1차조사1:1.
- P06 쉬스/2차조사1,000m, 검사500m, 작업자무제한.

- 모든제품공정 초안상태 유지.

### 구현 상태
- DB migration: 미확인/미구현으로 계획.
- Backend/Frontend: 저장소미연결, 구현여부확인불가.
- SimPy 전체모델: 실행검증안함.
- 실제CAD IN/OUT: 미확정.
- 테스트 문서 예상값: 산술검토, 구현테스트실행과다름.
- 기존roadmap파일: 미첨부, 이문서는대화기반재구성.

## 버전 제안

- patch: 의미를 바꾸지 않는 문구/오타.
- minor: 호환 가능한 기능/공정추가/검증규칙.
- major: DB/API/스냅샷의 비호환 변경.
- 문서버전과 개별제품공정버전, 엔진버전은 별개.
