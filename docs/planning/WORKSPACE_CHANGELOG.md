# 워크스페이스 변경 이력
## 1.1.0 — 2026-10-23
- 업로드 기술서 18개를 역할별 경로로 분배하고 상대 링크 수정.
- 업로드 ZIP 원본 보존 및 SHA-256 이관 목록 추가.
- Python 배치를 backend/src/simulation_platform으로 통일.
- 루트/영역별 AGENTS, README, 시작 지시문, 역할·파일 소유권, 인계·CR·ADR 양식 추가.
- 계약 승인 상태는 pending 유지. OpenAPI/마이그레이션/앱을 구현했다고 표시하지 않음.
- worktree 및 한 폴더 대안 운영, 테스트 DB·포트·생성 파일 충돌 방지 안내.
- 표준 라이브러리 문서 검증 도구, 문서 검사 CI, VS Code 작업 설정 추가.
- 첨부 CAD 파일은 용량·기밀성을 고려해 ZIP에서 제외하고 목록/해시만 기록.
- 제품6종 업무 값·미정 사항·원본 백로그 완료 여부는 변경하지 않음.

이후 변경은 사용자 공정 정정 / 기술 결정 / 구현 / 검증을 분리해서 기록한다.
