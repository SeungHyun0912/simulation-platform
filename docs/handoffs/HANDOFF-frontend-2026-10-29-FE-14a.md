- 참고 파일: `frontend/references/factory-labeler.html`(메인 체크아웃에만 있고 저장소에는 없음). 경로 도구(클릭으로 꼭짓점, 박스 클릭 시 중심 맞춤, 더블클릭·Enter 완료, Backspace·Esc, 선 더블클릭으로 점 삽입, 되돌리기)를 계약 모델(점 + 점 순서 경로)에 맞게 옮겼다. 박스 구분·축척 기준선·내보내기 등 나머지 기능은 범위 밖.

## 1. 바뀐 동작
| 항목 | 처리 |
|---|---|
| 경로 그리기 — 점 자동 생성 | 도면 빈 곳을 누르면 그 자리(m, 소수 첫째 자리)에 **새 점 P{n}** 을 만들어 경로에 잇는다 |
| 기존 점 선택 | 기존 점을 누르거나, 화면 **12px 안**을 누르면 새 점 대신 그 점을 쓴다. 패널 "기존 점 추가"(선택 상자)로도 고른다 |
| 설비·공간 누르기 | 첫 점이면 **산출(OUT)**, 아니면 **투입(IN)** 포트(공간은 ACCESS)의 점으로 잇는다. 포트가 점에 연결돼 있지 않으면 누른 자리에 점을 만들고 **포트를 자동 연결**, 출발·도착 포트도 자동으로 채운다 |
| 끝내기·취소 | 더블클릭·Enter·"경로 만들기"로 끝냄(출발·도착 포트를 비워 두면 첫·끝 점에 연결된 포트로 채우고, 못 정하면 이유를 알리고 계속). Backspace는 마지막 점 빼기(그 그리기에서 만든 점이면 점도 지움), Esc·취소는 **자동으로 만든 점·포트 연결까지 되돌림**. 마지막 점에서 마우스까지 미리보기 선 |
| 기존 경로 편집 | 선택 모드에서 경로 선 **더블클릭 → 그 자리에 점 끼워 넣기**(가까운 기존 점이 있으면 그 점). 경로 속성에 점마다 "빼기", "끝에 기존 점 추가" |
| 점 정리 | 점 표 위에 "쓰지 않는 점 N개 지우기"(포트 연결·경로 둘 다 없는 점) |
| 되돌리기·다시 하기 | 버튼과 Ctrl+Z / Ctrl+Y(Ctrl+Shift+Z). 끌기는 시작할 때 한 번만 기록, 경로 하나는 한 번에 되돌림. 입력 칸에 있을 때는 동작하지 않음 |
