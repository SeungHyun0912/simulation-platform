## 실제 구현 내용
- 지금까지 jsdom 테스트로만 검증했던 화면을 `pnpm vite`로 띄우고 설치된 Edge 헤드리스 스크린샷으로 처음 눈으로 확인했다(새 도구 도입 없음, 스크린샷은 저장소에 포함하지 않음).
- 발견·수정한 결함:
  1. 좁은 화면에서 고정 폭 사이드바가 본문을 압축 → 768px 이하에서 메뉴를 본문 위 가로 배치로 변경.
  2. 표의 `nowrap`이 그리드 열을 뷰포트보다 넓힘 → 앱 셸 그리드 열을 `minmax(0, 1fr)`로 변경.
  3. 필드 격자에서 힌트가 있는 필드 때문에 입력 상자 높이·위치가 어긋남 → 필드에 `align-content: start`.
  4. 경고만 있는 검증 패널이 오류와 같은 빨간 테두리 → 오류가 있을 때만 위험 색, 경고만이면 경고 색. 필드 경로 코드를 별도 줄로 분리.
  5. 충돌 안내의 두 버튼이 붙어 있음 → 작업 영역에 간격 추가.
- `frontend/docs/QA_CHECKLIST.md` 신설: 확인한 것과 확인하지 못한 것을 구분해 기록.

## 채택 결정과 근거
- 반응형 분기점은 48rem(768px). CSS 변수는 미디어 쿼리에 쓸 수 없어 값을 직접 사용했다.
