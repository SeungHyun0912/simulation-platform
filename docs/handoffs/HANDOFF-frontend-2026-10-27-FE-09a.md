## 1. 구현
- **병목(실행 상세 "병목" 섹션)**: 한 줄 요약, **판정의 한계(`limitations`)와 기준값(`thresholds`)을 항상 함께 표시**(계약 요구), 종류(저장 공간 부족·설비 가동 대기·대기 자재 적체, 모르는 종류는 원문)별로 묶어 순위·수준 배지(기호+글자)·위치(제품·단계 또는 대기 공간)·멈춘 양(작업물·분)·종류 안 비율·설명, 근거 수치는 펼쳐 보기(열린 구조: 아는 키는 한국어, 모르는 키는 원문). 종류별 3건 미리보기 + 모두 보기. 종류끼리 합산하지 않음을 안내. `quality_status` ≠ complete면 경고. 409는 "결과 없음" 안내.
- **설비 타임라인(실행 상세)**: 구간 단위 주(기본)·일·월·전체, 설비별 구간 가동률 표(`DataTable`, 칸 진하기 = 가동률 + 숫자, 처리·준비·예약·막힘·유휴 분은 칸 title), 설비 20대씩 + "설비 더 보기", "이 실행에서 쓰인 설비만"(기본 켬, 숨긴 수 표시). "상태 보기" → 고른 구간만 `from_min`·`to_min`으로 잘라 받는 **상태 간트**(SVG + 같은 내용의 표, 범례, 모르는 상태는 원문, 구간 200건씩 더 보기, 구간 선택).
- **두 실행 비교**(`/projects/:p/runs/:a/compare/:b`, 실행 상세의 "다른 실행과 비교"에서 결과가 있는 실행을 골라 이동): 비교 불가(엔진 버전 다름)·경고를 **먼저**, 두 실행 상태·종료 시각, 입력 차이(`path`는 열린 문자열), 제품별 지표 기준/비교/차이/비율(null → "해당 없음"·"비교 불가"), 양쪽 병목 상위 5, 지표 차이(구간·지표·"달라진 값만" 기본 켬, 일·주·월은 지표를 골라야 요청). "기준·비교 바꾸기". 같은 실행 422·결과 없음 409 안내.
