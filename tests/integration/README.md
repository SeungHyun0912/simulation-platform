# 첫 실제 통합 테스트
현재 자동 테스트 구현 없음. 다음 시나리오를 구현할 때 frontend/Backend 테스트와 연결합니다.
1. 실제 PostgreSQL·API·UI 시작, Mock 완전 비활성화 확인.
2. 허용 조직에서 프로젝트 생성, 설비 생성, IN/OUT 2개 원자 생성 확인.
3. 저장공간·도킹 지점 생성, 설비와 다른 포트/용량 정책 확인.
4. 프로젝트 B로 전환하고 프로젝트 A 자산 요청이 거부됨을 확인.
5. 표시 코드 변경 후 내부 ID와 연결 유지 확인.
6. 동시 편집: 첫 요청 성공, 오래된 If-Match 412, 새로고침/재적용 UX 확인.
7. unknown 저장과 0 저장이 서로 다른 의미로 보존되는지 확인.
8. 승인 자산/공정 버전 불변, 새 초안 작성 경로 확인.
9. 서비스 중단·422/404/500에서 UI 메시지·request ID·재시도 확인.
10. 결과·로그와 실제 명령/환경을 docs/handoffs에 남김.
DB와 실제 사용자 데이터는 테스트 전용 환경과 분리합니다.
